# React Conditional Render App

A small React + Vite demo of conditional rendering. A button toggles a login state, and the page shows either "Welcome back!" or "Please log in."

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – production build
- `npm run preview` – preview the production build
- `npm run lint` – run ESLint
